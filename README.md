# 🗺️ Travler

> **로컬 기반 나만의 여행 & 산책 기록 아카이빙 애플리케이션**  
> 외부 서버나 DB 업로드 없이, 기기 내 사진/동영상의 메타데이터(GPS, 일시)를 기반으로 구글 맵과 연동하여 위치를 시각화하고 코멘트를 남길 수 있는 크로스 플랫폼(Android/iOS) 로컬 앱입니다.

---

## 📌 주요 특징
- **100% On-Device / Privacy-First**: 외부 서버 통신 없이 기기 로컬 스토리지에서 직접 미디어를 스캔 및 캐싱합니다.
- **Google Maps 기반 시각화**: 사진 및 동영상의 GPS 좌표를 파싱하여 지도 위에 마커/클러스터로 직관적 표출.
- **로컬 코멘트 & 마크업**: 미디어 식별자 기반으로 나만의 메모/코멘트를 기기 내 로컬 DB(Drift/SQLite)에 안전하게 저장.
- **자동 분류 & 정렬**: 시기별(연도/월/일 타임라인) 및 지역별(역지오코딩 기반) 자동 분류 지원.
- **크로스 플랫폼**: Flutter 기반으로 Android(Galaxy 실기기 우선) 및 iOS 확장 지원.
