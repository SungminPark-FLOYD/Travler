# Agent Guidelines & Rules

Please strictly follow the project rules defined in [PROJECT_RULES.md](file:///D:/intelij_workspace/UntitleApp/UntitleApp/PROJECT_RULES.md).

## Mandatory Operational Protocol
1. **Pre-Action Notification & Plan Sharing:** Before making any file modifications, creations, or deletions, explicitly explain the planned actions (Action items, target files, reasons) and summarize the expected side effects/impact to the user.
2. **Think Before Coding:** Clarify ambiguities with the user before assuming requirements.
3. **Simplicity First:** Write minimal, idiomatic, and concise code. Avoid unnecessary abstractions.
4. **Surgical Changes:** Modify only target files/lines; do not refactor untouched files.
5. **Goal-Driven Execution:** Break down tasks into clear, step-by-step deliverable units.
